# PR Code Review Lab

This repository is used for learning **code review through Pull Requests**.

⚠️ The code intentionally contains:
- bugs
- bad practices
- security issues
- design problems

Your task is NOT just to make it work, but to:
- improve readability
- improve safety
- improve design
- explain your reasoning in PRs and reviews

## Rules
- One logical change per PR
- Clear PR description
- Be respectful in reviews

## Tasks

### Easy

- add input validation

- improve naming

- improve error messages

### Medium

- hash passwords

- refactor file access

- add meaningful tests

### Advanced

- redesign auth flow

- separate IO from logic

- introduce config management

- security hardening
